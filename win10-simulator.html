🎓 Roteiro do aluno
  1. Abra o menu Iniciar ou use Win + R.
  2. Memória virtual: Iniciar → Configurações → Sistema → Sobre → Configurações avançadas do sistema → Desempenho → Configurações → Avançado → Alterar.
  3. Limpeza: Explorador → Este Computador → Disco C: → Propriedades → Limpeza de Disco.
  4. Otimização: Disco C: → Propriedades → Ferramentas → Otimizar.
  5. Terminal: pesquise cmd no Menu Iniciar, ou use Win + R.
  6. Gerenciador de Tarefas: Ctrl + Shift + Esc → Desempenho / Inicializar. Informações do Sistema: Win + R → msinfo32.
  7. Teste sfc /scannow e chkdsk C: /f.
